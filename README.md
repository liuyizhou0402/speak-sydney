# Speak Sydney

一个免费、开放的 30 天职场英语口语训练网站，面向准备悉尼数据分析实习面试的中文母语学习者。

网站不需要注册，不会上传录音或录像。课程进度仅保存在使用者自己的浏览器中。

**在线使用：<https://liuyizhou0402.github.io/speak-sydney/>**

## 使用方式

通过 GitHub Pages 公网地址可以直接使用。下载项目后，也可以双击 `index.html` 浏览课程；摄像头与录音功能通常需要在本地服务器环境运行：

```bash
python3 -m http.server 4173
```

然后打开 `http://localhost:4173`。建议使用最新版 Chrome、Edge 或 Safari，并允许浏览器访问麦克风和摄像头。所有练习进度只保存在当前浏览器中，录音录像不会上传。

## 功能

- 完整 30 天双语训练路线
- 数据分析实习面试高频题和 STAR / PREP 等表达框架
- 英文示范答案朗读与语速控制
- 情景对话与本地录音回放
- 摄像头视频模拟面试、倒计时和本地回放
- 完成状态、连续打卡与自评分本地保存
